# CSS Frameworks - CA

Front-end social media application built with Tailwind CSS for the CSS Frameworks course assignment.

## Features

## Authentication UI

- Login and Registration form layout
- Required form field validation
- Password minimum length requirement (8 characters)
- Authentication used as the application entry point

## Feed Page

- Responsive grid layout of post cards
- List of post thumbnails with image backgrounds
- Search and sort UI controls
- Create post form section
- Post cards include:
  - Author name and timestamp
  - how many likes, shares and comments
  - Hover overlay interaction
  - Title and description text

## Profile Page

- User profile section with:
  - Avatar image
  - Username and bio
  - Followers / Following display
  - Follow button
- Post creation form
- Responsive card grid of user posts

## Navigation

- Responsive navigation layout
- Mobile menu toggle functionality (JavaScript)
- Logged in state with welcome message
- Logout button displayed when authenticated

## Styling and Framework

- Built using Tailwind CSS utility-first approach
- Custom color palette extensions 
- Responsive design using Tailwind breakpoints
- Consistent spacing and utility-first styling approach

## Tech stack

- **HTML5**
- **Tailwind CSS**
- **JavaScript**
